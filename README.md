## Бизнес-домен

Камеры наблюдения формируют кадры, которые анализируют GPU-узлы. Если все узлы заняты, кадр ждёт в буфере. Актуальность кадра падает со временем, поэтому при переполнении вытесняется самый старый кадр, а при освобождении узла берётся самый свежий.

## Расшифровка кода варианта

Код: `ИБ ИЗ1 ПЗ2 Д1ОЗ3 Д1ОО3 Д2П1 Д2Б2 ОР1 ОД2`

| Код | Смысл | Реализация |
|---|---|---|
| ИБ | бесконечный источник | `Source` формирует заявки без ограничения числа |
| ИЗ1 | пуассоновский поток | интервал между кадрами `-ln(U)/λ` |
| ПЗ2 | равномерное время обслуживания | `a + (b - a) * U`, U из [0, 1) |
| Д1ОЗ3 | постановка на свободное место | первая свободная позиция буфера с начала, без сдвига |
| Д1ОО3 | отказ: самая старая в буфере | при полном буфере удаляется заявка с минимальным `arrivalTime`, на её место встаёт новая |
| Д2П1 | выбор прибора по приоритету номера | перебор с наименьшего номера, берётся первый свободный |
| Д2Б2 | выбор заявки LIFO | из буфера берётся заявка с максимальным `arrivalTime` |
| ОР1 | сводная таблица результатов | автоматический режим, итоговая таблица |
| ОД2 | схема модели и текущее состояние | пошаговый режим, состояние по шагам |

## Принятые решения

- **Триггерные события.** `GENERATE` запускает `DispatcherIn`, `DEVICE_FREE` запускает `DispatcherOut`. Сами по себе диспетчеры не работают.
- **Диспетчер постановки** может отправлять заявку сразу на свободный прибор, минуя буфер (вариация из описания бизнес-домена). У него есть ссылки на `Buffer` и `DevicePool`.
- **Отказы только в буфере.** Приборы не отказывают, они бывают заняты. Отказ это вытеснение самой старой заявки (Д1ОО3), поток данных при этом не прекращается.
- **Инвариант.** Если в буфере есть заявки, свободных приборов нет. Поэтому при `DEVICE_FREE` с непустым буфером свободен только освободившийся прибор.
- **Указатели и пакеты** в варианте не используются (Д1ОЗ3 без указателя, Д2Б2 без пакетов), поэтому на шагах они не отображаются.
- **Календарь событий** в пошаговом режиме выводится таблицей на каждом шаге: сгенерирована, в буфер/на прибор, вытеснена, выбрана из буфера, отправлена на обслуживание, обслужена.

## Статистика (ОР1)

- P отказа = вытеснено / поступило
- Среднее время ожидания = среднее по заявкам `serviceStartTime - arrivalTime`
- Среднее время в системе = среднее по обслуженным `serviceEndTime - arrivalTime`
- Загрузка прибора = суммарное время занятости / T_end
