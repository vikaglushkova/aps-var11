## Бизнес-домен

Камеры наблюдения формируют кадры, которые анализируют GPU-узлы. Если все узлы заняты, кадр ждёт в буфере. Актуальность кадра падает со временем, поэтому при переполнении вытесняется самый старый кадр, а при освобождении узла берётся самый свежий.

## Файлы

| Файл | Содержание |
|---|---|
| `sequence.puml` | главный сиквенс: HappyFlow, постановка в буфер, отказ, выборка из буфера, цикл ожидания |
| `class-diagram.puml` | диаграмма классов с методами и ссылками |
| `task-generation-and-placement.puml` | генерация кадра и постановка (дорожки) |
| `task-selection.puml` | выбор заявки из буфера и постановка на прибор (дорожки) |
| `end-of-service.puml` | завершение обслуживания (дорожки) |
| `simulation-loop.puml` | общий цикл моделирования, пошаговый и автоматический режим |
| `flowchart-swimlanes.puml` | сводный flowchart с дорожками |
| `imgs/` | SVG, получаемые командой `./render.sh` |
